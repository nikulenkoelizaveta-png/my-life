# My Life

Личный планер владелицы. Перед любыми изменениями прочитай `docs/SYSTEM.md`: там устройство, формат данных и правила.

Главное:
- Весь планер в одном файле `index.html`, сборки нет. Пуш в `main` публикует сайт через GitHub Pages за 1–2 минуты.
- Записи в Supabase, проект `oyvxcdoguysvzzyyrugp` («My Life»), таблица `public.docs` (одна строка на ключ из `KEYS`, RLS: только владелец). Проект `planerv` и репозиторий `kabinet` — другие продукты, их не трогать.
- Не переименовывать ключи в `KEYS` и не менять формат существующих полей без переноса данных.
- Никогда не класть в код ключ `service_role` или пароли.
- Владелица пользуется в основном телефоном: проверять вёрстку на ширине около 390px. Общается по-русски, интерфейс на русском.
- Владелица не программист: объяснять простыми словами, задачи в планер не придумывать за неё, перед заметными изменениями интерфейса уточнять.
- После изменений обновить `docs/SYSTEM.md`, если поменялось устройство или формат данных.
